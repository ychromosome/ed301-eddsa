# Ed301-EdDSA-v1 vectors

`ed301-eddsa-v1.json` and `ed301-eddsa-edge-v1.json` are generated by
`../../tools/generate_ed301_eddsa_v1_vectors.py` from the sealed draft-00
seeds, messages and structural edge cases plus the independent variable-time
Python transcript in `../../provider-tests/oracle/ed301_eddsa_v1/`.

Reproduce into a separate directory and compare bytes:

```sh
sha256sum -c inputs/v1/SHA256SUMS
tmp=$(mktemp -d)
PYTHONDONTWRITEBYTECODE=1 python3 -I \
    tools/generate_ed301_eddsa_v1_vectors.py "$PWD" "$tmp"
cmp inputs/v1/ed301-eddsa-v1.json "$tmp/ed301-eddsa-v1.json"
cmp inputs/v1/ed301-eddsa-edge-v1.json "$tmp/ed301-eddsa-edge-v1.json"
```

The Python implementation is test-only and variable-time. It is independent
of the Rust transcript implementation but intentionally reuses the separately
tested Python curve and encoding arithmetic because ED301-v1 is unchanged.
